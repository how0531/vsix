# VSIX Repository

This repository stores VS Code extensions (.vsix).

## Included Extensions

### Anthropic Claude Code
- **File**: `anthropic.claude-code-2.1.260-win32-x64.vsix`
- **Version**: 2.1.260
- **Platform**: Windows x64 (`win32-x64`)

## How to Install

### Method 1: VS Code UI
1. Download the `.vsix` file.
2. Open VS Code.
3. Go to the **Extensions** view (`Ctrl+Shift+X` / `Cmd+Shift+X`).
4. Click the **...** (Views and More Actions) menu in the top-right corner of the Extensions pane.
5. Select **Install from VSIX...** and choose the downloaded `.vsix` file.

### Method 2: Command Line
```bash
code --install-extension anthropic.claude-code-2.1.260-win32-x64.vsix
```
